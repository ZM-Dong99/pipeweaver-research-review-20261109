## 2026年11月17日参数规模结果

新增54次 `gpt-6.1-sol` 调用，覆盖三个电路家族的9个参数实例，两组每实例各3次。返回53份不同RTL，49份满足全部资格约束，47份取得有效时序改善。累计可核验响应ID为421个。

| STA组电路家族 | 参数规模 | 各规模中位保留时序收益 | 有效优化/计划 |
|---|---|---|---:|
| ALU | 16 / 32 / 64位 | 14.29% / 32.53% / 37.33% | 7/9 |
| 优先编码器 | 64 / 128 / 256路 | 30.06% / 32.74% / 43.08% | 8/9 |
| CRC32更新核 | 4 / 8 / 16位输入 | 0.00% / 2.06% / 1.89% | 7/9 |

CRC16位输入实例的最好合格STA候选面积降低53.43%。所有收益按相同原始基线与110%面积约束计算。失败保留在分母中，无有效优化时保留原始实现。每参数每组3次，当前结果用于探索性规模比较。

完整组别、失败反例、候选归属、预先记录的留出路由评估及训练成本见[参数实验报告](PARAMETER_REPORT.md)与[机器可读统计](PARAMETER_ANALYSIS.json)。[参数复现说明](PARAMETER_REPRODUCE.md)提供统一入口。9个基线及53份保存RTL已全量重测，62项状态和已完成指标匹配冻结记录，详见[重测结果](output/parameter_review_validation_20261117/full_reproduction.json)。

## STA代表性成果

下表均为真实STA组候选相对各自原始RTL的改善。候选通过源级与映射后等价、同条件综合与STA、电气检查及110%面积预算。主要模型调用名称为`gpt-6.1-sol`。完整候选归属、源码哈希和计数口径见主报告及案例索引。

| 固定电路实例 | 原始到候选延迟 ns | 延迟降低 | 映射面积变化 |
|---|---:|---:|---:|
| 256路优先编码器 | 2.60 → 1.49 | 42.69% | +5.65% |
| 64位ALU | 3.05 → 1.85 | 39.34% | +3.60% |

| 8×8乘法器 | 2.45 → 2.16 | 11.84% | +7.17% |

表中为各固定实例的代表性合格候选。优先编码器、选择器和ALU在四电路批次的STA组分别有8/10、9/10和9/10合格改进，CRC独立批次为7/10。主报告另含地址计算补充案例、早期加法器和实际验证反馈修复案例。
