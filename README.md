# PipeWeaver STA指导RTL优化研究

实验资料截止2026年11月9日，STA主线整理更新于11月10日。本仓库是面向老师核查的整理快照，Git初始提交对应审阅材料整理时间。各实验的协议、调用记录、代码快照和工具日志提供研究过程记录。

## 建议阅读顺序

1. [STA主线汇报](STA_REPORT.md)重点展示STA组相对原始RTL的合格优化。优先编码器和ALU的代表性延迟分别降低42.69%与39.34%，选择器、译码器和CRC还同时降低面积。
2. [STA案例与代码索引](STA_CASES.json)逐项绑定STA候选、模型调用名称、原始基线和测量结果。完整研究材料通过[37项结论索引](CLAIMS.json)关联。
3. [复跑说明](REPRODUCE.md)提供7组STA案例的重测命令。[STA独立复测记录](STA_REPRODUCTION.json)保存已完成的14次本地EDA结果。

## STA代表性成果

下表均为真实STA组候选相对各自原始RTL的改善。候选通过源级与映射后等价、同条件综合与STA、电气检查及110%面积预算。主要模型调用名称为`gpt-6.1-sol`。完整候选归属、源码哈希和计数口径见主报告及案例索引。

| 固定电路实例 | 原始到候选延迟 ns | 延迟降低 | 映射面积变化 |
|---|---:|---:|---:|
| 256路优先编码器 | 2.60 → 1.49 | 42.69% | +5.65% |
| 64位ALU | 3.05 → 1.85 | 39.34% | +3.60% |
| 10路8位选择器 | 1.04 → 0.77 | 25.96% | −3.97% |
| 8位译码器 | 1.06 → 0.80 | 24.53% | −20.26% |
| CRC32字节更新核 | 0.98 → 0.84 | 14.29% | −36.85% |
| 8×8乘法器 | 2.45 → 2.16 | 11.84% | +7.17% |

表中为各固定实例的代表性合格候选。优先编码器、选择器和ALU在四电路批次的STA组分别有8/10、9/10和9/10合格改进，CRC独立批次为7/10。主报告另含地址计算补充案例、早期加法器和实际验证反馈修复案例。

## 第一层检查

使用Python3.10或以上，在仓库根目录执行。

```sh
python tools/verify.py
```

该命令只读取归档，用标准库校验文件哈希、结论证据、244个主要批次记录的资格判定与中位数、327个已保存响应ID、续轮依赖和FCS指标。输出passed、checks及failures。文件完整性证明当前归档的一致性，历史结果由协议、日志和独立复跑共同支撑。

## 第二层检查

[EDA复跑说明](REPRODUCE.md)提供STA汇报案例及完整研究代表性实例的原始与候选重测入口。新运行写入独立runs目录，实际调用本地Yosys、Slang和WSL OpenSTA，使用者提供相同哈希的Liberty及已安装工具。

## 归档范围

本仓库包含源码、协议、模型可见响应、失败记录、源级与门级证明日志、实际映射网表、STA报告、检查配置和机器可读结果。大型PDK、完整GDS/LEF、工具二进制及部分可再生成中间文件另按来源准备，其原路径和哈希列在[省略资产清单](OMITTED_ASSETS.json)。物理层审阅以原始报告、配置、负例和产物哈希为入口，完整物理重跑需要配套PDK与资产。

默认核查与重测的模型调用数为0。模型调用代码作为研究实现保留，真实联网实验由明确预算、材料和授权单独管理。
