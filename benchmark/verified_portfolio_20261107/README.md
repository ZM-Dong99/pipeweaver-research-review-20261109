# Verified development portfolio

Three fixed instances and ten historical candidate source files, copied without logic edits.

`registry.json` records exact parameters, original sources, per-file SHA256 and physical line counts; `registry.sha256` detects registry changes. Origin paths point to retained project experiments. Keep the original copyright headers and provenance when using these files.

These are already exposed development artifacts, not held-out benchmarks, new model outputs or general parameterized rewrite rules. Every use through `agents.portfolio_loop` reruns proof/mapping/STA and checks the current original-relative budget. Do not infer correctness for other parameter values from the stored instances.

See the project-root `README_VERIFIED_PORTFOLIO.md` for use, outputs and limitations.
