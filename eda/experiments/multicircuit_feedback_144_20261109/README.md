## 固定方案

- 六类固定组合实例为256路优先编码器、64位ALU、CRC32字节更新、16位比较器、8位至256位译码器和8×8位乘法器。
- 第一轮120次，各电路无STA组与STA组各10次。调用顺序按固定随机种子交错安排，各组提示在调用前冻结。
- 第二轮24次，对第一轮预先指定的trial 1、2继续优化。无STA组获得自己的上一份RTL，STA组额外获得实际验证结果和STA路径。第二轮存在父子依赖，单独统计。
- 每次请求最多16,000完成token、600秒，最多6并发，无自动重试或替补槽位。连续3个完成任务发生传输失败后停止安排新请求，已在途请求完成。
- 请求完成token合计上限2,304,000，另有输入token。没有可靠的货币费用估算，失败可能计费。

## 接受规则

所有输入取任意二进制值，原始输出行为必须保持。源级及实际映射后等价证明、PPA流程和电气检查均通过，面积不超过新复现基线的110%，TNS不退化，最大到达时间严格降低，才记为合格改进。

失败、超时、越界及无收益候选均保留在预定分母中。每电路每组主指标为10个槽位的基线回退后延迟中位数，同时报告有效改进数、源代码和映射网表去重数。重复EDA和第二轮依赖候选不能当作新的独立第一轮样本。
